# dotmanager

TUI dotfile manager: adopts config files into a git repo, symlinks them back, and syncs with a remote.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/gbsaito/dotmanager/main/install.sh | sh
```

Pin a version:

```sh
DOTMANAGER_VERSION=v0.1.0 curl -fsSL https://raw.githubusercontent.com/gbsaito/dotmanager/v0.1.0/install.sh | sh
```

## Uninstall

```sh
curl -fsSL https://raw.githubusercontent.com/gbsaito/dotmanager/main/uninstall.sh | sh
```
